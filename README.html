LUFS Lens 1.2.0

User guide · Windows loudness analyzer

Check your audio against your own loudness target.
Select files, choose a target, and review the HTML and CSV reports. Analysis runs locally and does not change your audio.

What it does

LUFS Lens analyzes your audio files and checks:

  • Integrated LUFS (overall loudness)
  • True Peak (inter-sample clipping risk)
  • Sample Peak
  • LRA (Loudness Range)
  • Sample rate and technical metadata
Initial settings:
Target -14 LUFS, tolerance +/-0.5 LU, true-peak limit -1 dBTP. The expected sample rates are 44.1 or 48 kHz. The target is your comparison reference, not a universal mastering requirement.

Setup and updating

Use 64-bit Windows with Windows PowerShell and FFmpeg/ffprobe. Extract the ZIP completely into a folder you can write to before starting it.

Already have LUFS Lens? Close the app and keep a backup of your old folder. Copy the new app files into that folder, replacing matching files. Keep your existing ffmpeg and Reports folders. If you already customized settings.txt, keep your own copy or restore your target afterward.

The v1.2.0 app-update ZIP does not contain FFmpeg. For a fresh installation, get a Windows build through the official FFmpeg download page and place both ffmpeg.exe and ffprobe.exe in ffmpeg\bin\ beside the launcher. Alternatively, make both programs available on PATH. Existing bundled installations already have these files.

How to use

After selecting or dropping your files, enter your target LUFS in the console. Press Enter to use your saved default (initially -14 LUFS). Any finite numeric target is accepted, including decimals such as -16.5 (or -16,5). The selected target applies to the entire batch and is included in both reports. Status and suggested gain use this target, with a tolerance of +/-0.5 LU. This tool analyzes audio; it does not change your files.

For PowerShell use without a prompt:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\app\LUFS-Lens.ps1" -TargetLUFS -16 -Paths "C:\Music\track.wav"

To change the startup default, open settings.txt next to LUFS Lens.bat in a text editor and change TargetLUFS=-14 to your preferred value, for example TargetLUFS=-9. An explicit command-line target takes priority over the file. Entering a target at the prompt changes only that run; it does not rewrite your saved default. If the settings file is missing or invalid, the default is -14 LUFS.

Option A – Double-click

  • Open LUFS Lens.bat
  • Select one or multiple files
  • Enter your target or press Enter for the displayed default
  • Follow the track count, analysis stage and elapsed time in the console
  • The report opens automatically

Option B – Drag & Drop

  • Drag a file or folder onto LUFS Lens.bat
  • Enter your target or press Enter for the displayed default
  • Folders include supported files in their subfolders
Your files → Your target → Local analysis → HTML + CSV reports

Supported extensions: WAV, FLAC, AIF/AIFF, MP3 and M4A. Accented and non-Latin filenames are supported. Reports open after the entire batch finishes. Elapsed time updates between stages and completed tracks; it is not a remaining-time estimate. Both full analysis passes are retained.

Where are reports saved?

All reports are saved inside the tool folder:

Reports\ beside LUFS Lens.bat.

  • loudness_report_TIMESTAMP.html
  • loudness_report_TIMESTAMP.csv

HTML = visual overview.
CSV = spreadsheet-friendly data.

Reports include your selected target and local file paths. They remain on your computer until you delete or share them. Review filenames and paths before sharing a report. The temp folder can contain the last list of selected file paths; you may clear it after closing the app.

Understanding the Metrics

Integrated LUFS
Overall average loudness of the track. Compare this measurement with the target you selected for this batch.

True Peak (dBTP)
Measures inter-sample peaks that can exceed digital 0 dB. The report checks it against the app's -1 dBTP limit. Remeasure after processing or encoding.

Sample Peak (dBFS)
Highest raw digital sample value. Useful for detecting hard clipping.

LRA (Loudness Range)
Indicates dynamic variation. Low LRA = heavily compressed. Higher LRA = more dynamic contrast.

Status Verdict

Gain Advice compares the gain needed to reach your target with the available true-peak headroom. For example, if +4 dB is needed but only +1 dB is available, the report flags GAIN EXCEEDS PEAK HEADROOM and shows the estimated peak after that gain. Gain alone cannot meet both limits; you can choose a lower target or adjust the master. This is an estimate from measured values, so remeasure the final processed or encoded export. No audio is modified.

READY
Within LUFS tolerance, safe true peak, correct sample rate, and target gain fits peak headroom.
ADJUST
Outside the selected target or another check needs attention. Read Issues and Gain Advice.
ERROR
Analysis failed. Check file integrity or format.

LUFS HIGH / LUFS LOW: outside the target tolerance. TRUE PEAK HOT: measured peak above -1 dBTP. SAMPLE RATE CHECK: a sample rate other than 44.1 or 48 kHz; this is a review flag, not proof of bad audio. READY describes these checks only and is not a platform approval or a guarantee of audio quality.

Troubleshooting

  • No supported files: select one of the extensions listed above and check that the path still exists.
  • FFmpeg/ffprobe not found: check the two executable paths shown in Setup. Extract the whole archive before running.
  • Invalid saved target: use a line such as TargetLUFS=-9 in settings.txt. Do not add units or quotes. Invalid settings produce a warning and use -14.
  • Report did not open: open the newest HTML file in Reports manually.
  • Analysis error: try playing the file and re-exporting it. Very short or silent audio may not produce finite loudness measurements. Debug text may appear in Reports when parsing fails.
  • Long track seems busy: the current pass can take time; stage and elapsed-time text update at checkpoints.
  • Need to cancel: press Ctrl+C in the console. A cancelled batch may not produce a final report.
  • Windows or workplace policy blocks scripts: follow your device policy or ask its administrator. Administrator privileges are not normally needed for this app.

For predictable results, use ordinary audio files with one audio stream. Multi-stream containers can select different streams for metadata and measurements. The tool does not automatically normalize, limit or export audio.

  • Gain Advice flags insufficient true-peak headroom.
